# X-002 — Repository settings: branch protection and merge options on GitHub

**Lane:** User · **Milestone:** M0 — Kickoff · **Needs:** nothing

## Done when
- [ ] `main` requires a PR and the CI checks `Policy`, `Rust` and `Android` to pass
- [ ] Squash merge allowed; "Automatically delete head branches" on
- [ ] Force-push and deletion of `main` blocked

## Steps
1. GitHub → Settings → Branches → Add rule for `main`: require a pull request (0 approvals), require status checks `Policy (ownership, tasks, Python tools)`, `Rust`, `Android (unit tests, lint)`, block force pushes.
2. Settings → General → Pull Requests: allow squash merging, tick "Automatically delete head branches".

## Context
- The agents are denied `gh repo edit` and `gh api -X PUT` by the guard, so only you can change these. The pre-push hook is the local backstop; branch protection is the server-side one.
- Both agents use your GitHub login, so do not require an approving review from another account — the signed review comments (`AGENTS.md` §5.4) are the review.
- Rules: `AGENTS.md`. Ownership: `OWNERS.toml`. If this task is bigger than ~2 days of work, split it into new tasks in your own lane.
